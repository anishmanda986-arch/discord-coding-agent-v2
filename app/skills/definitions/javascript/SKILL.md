# Modern JavaScript ESNext

## Purpose
Write modern, clean, and idiomatic JavaScript.

## When to Use
Writing Node.js scripts, web apps, and utility functions.

## Workflow
1. Use ES Modules (import/export)
2. Handle async with async/await
3. Use structuredClone and modern built-ins.

## Best Practices
Avoid mutations. Use const by default.

## Common Failures & Pitfalls
Unhandled promise rejections, callback hell.

## Verification Checklist
- [ ] All promises caught or awaited
- [ ] Clean module exports.
