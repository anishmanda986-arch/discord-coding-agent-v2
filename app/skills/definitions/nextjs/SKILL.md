# Next.js Framework Master

## Purpose
Harness Next.js App Router, Server Components, and SSR capabilities.

## When to Use
Building production React fullstack apps with Next.js.

## Workflow
1. Configure app directory routes
2. Use React Server Components by default
3. Mark interactive components with 'use client'
4. Optimize metadata & images.

## Best Practices
Fetch data directly in Server Components. Secure environment variables.

## Common Failures & Pitfalls
Accidental 'use client' on everything, route handler runtime errors.

## Verification Checklist
- [ ] Correct server/client boundary
- [ ] Dynamic routes validated
- [ ] Fast build time.
