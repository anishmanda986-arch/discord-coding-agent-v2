# Git Workflow & Version Control

## Purpose
Manage codebase version control cleanly and safely.

## When to Use
Tracking changes, generating diffs, branching, committing.

## Workflow
1. Check status
2. Stage specific files
3. Write descriptive commit
4. Review unified diff.

## Best Practices
Atomic commits. Clean commit messages.

## Common Failures & Pitfalls
Accidentally committing .env or build artifacts.

## Verification Checklist
- [ ] .gitignore in place
- [ ] Clean working tree.
