# Kotlin & Jetpack Compose

## Purpose
Write idiomatic Kotlin with coroutines and declarative UI.

## When to Use
Kotlin services or Jetpack Compose apps.

## Workflow
1. Use data classes & sealed classes
2. Handle concurrency with CoroutineScope
3. Compose UI declaratively.

## Best Practices
Leverage null-safety operators. Use StateFlow for reactive state.

## Common Failures & Pitfalls
Leaking coroutine scopes, improper Compose recompositions.

## Verification Checklist
- [ ] Coroutines structured
- [ ] Null safety verified.
