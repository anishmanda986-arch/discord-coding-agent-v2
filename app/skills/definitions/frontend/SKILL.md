# Frontend Engineering

## Purpose
Create fast, accessible, and responsive user interfaces.

## When to Use
When implementing UI components, layouts, styling, and client state.

## Workflow
1. Break UI into components
2. Style with Tailwind CSS
3. Manage local/global state
4. Add keyboard accessibility.

## Best Practices
Use semantic HTML. Maintain optical hierarchy and sufficient contrast.

## Common Failures & Pitfalls
Uncontrolled re-renders, hardcoded px spacing, broken mobile layouts.

## Verification Checklist
- [ ] Accessible colors
- [ ] Touch targets >= 44px
- [ ] Fast render performance.
