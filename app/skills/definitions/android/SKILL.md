# Android Application Development

## Purpose
Build robust Android applications using Gradle and modern Android APIs.

## When to Use
Android project inspection, build fixes, or Kotlin code.

## Workflow
1. Check AndroidManifest.xml
2. Configure build.gradle dependencies
3. Implement activities/fragments
4. Test with Gradle.

## Best Practices
Handle configuration changes. Follow material design guidelines.

## Common Failures & Pitfalls
Missing permissions in manifest, main thread network calls.

## Verification Checklist
- [ ] Manifest updated
- [ ] Gradle builds without errors.
