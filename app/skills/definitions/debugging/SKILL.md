# Systematic Root-Cause Debugging

## Purpose
Diagnose and fix software defects with precision.

## When to Use
When tests fail, builds break, or exceptions are thrown.

## Workflow
1. Reproduce failure
2. Inspect stack trace
3. Formulate hypothesis
4. Apply minimal surgical fix
5. Verify test passes.

## Best Practices
Fix the root cause, not just the symptom. Avoid shotgun debugging.

## Common Failures & Pitfalls
Blindly adding try/except without understanding the error.

## Verification Checklist
- [ ] Root cause identified
- [ ] Targeted fix applied
- [ ] Regression test added.
